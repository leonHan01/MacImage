# MacImage

MacImage 是一个面向 macOS 的本地图片浏览与整理工具，使用 Electron 构建。它支持按文件夹浏览图片、标签管理、图片竞赛评分、重复图片检测、图片迁移以及可恢复的回收站操作。

[English](readme.md)

## 功能概览

- 图片浏览
  - 打开图片文件夹，扫描当前目录中的图片文件（不递归扫描子目录）。
  - 支持列表视图、缩略图网格视图和大图瀑布流视图。
  - 支持按文件名、文件大小、修改时间、Elo 评分或随机顺序排序。
  - 支持在预览窗口中切换上一张/下一张、缩放、拖拽查看，以及在 Finder 中定位图片。
  - 点击预览底部工具栏中的“复制当前图片”，将图片内容复制到系统剪贴板。
  - 缩略图会缓存到本地，减少重复生成缩略图的开销。

- 标签与分类
  - 创建、编辑、删除标签，并为标签设置颜色、分类和单字母快捷键。
  - 内置人物、风景、物品、事件、情感、风格、其他等分类，也可以自定义分类和图标。
  - 在侧边栏按标签筛选图片，也可以快速筛选未打标签的图片。
  - 预览图片时可以快速添加标签；标签和评分按图片内容指纹保存，图片移动后仍可关联原有数据。
  - 内置“红心”标签，预览时按 `F` 可切换喜欢状态并自动进入下一张。

- 图片竞赛与评分
  - 从当前文件夹中发起图片竞赛，按轮次筛选图片。
  - 每组支持 2～8 选 1，获胜结果会更新图片的 Elo 评分。
  - 可按 Elo 评分排序，便于查看高分图片。
  - 竞赛窗口支持使用数字键 `1`～`8` 选择对应图片。

- 大图瀑布流整理
  - 支持 2、3 或 10 宫格批量浏览；2 宫格中的图片从左侧紧邻并排显示。
  - 各宫格模式中都可右键图片，直接将其标记为 1 分。
  - 操作集中在顶部单行工具栏；图片内显示透明的复制、评分按钮，隐藏文件名，避免占用图片展示空间。
  - 同页打分和刷新会复用已加载的图片，减少重复重建。
  - 为图片选择 1～3 分；保留最近 5 轮完整图片，可用“上一页”或方向键上连续返回，恢复该轮评分和宫格布局。超过 5 轮或退出应用时再提交整理：已评分图片移到目标文件夹，未评分图片直接进入 macOS 系统废纸篓，无需固定回收站目录。
  - 工具栏显示本页已选数量；悬浮可查看待提交、累计汇集和移入废纸篓的数量及文件大小。

- 重复图片检测
  - 检测当前文件夹中内容完全相同的图片。
  - 可以查看重复组、在 Finder 中定位图片，或一键将每组中除参考图片外的重复图片移入回收站。

- 小图片清理
  - 可填写大于 0、最大 300 KB 的阈值，扫描当前文件夹中小于该大小的图片。
  - 支持逐张定位或移入回收站，也可确认后批量清理；可使用 `Cmd + Z` 撤销最近一次批量操作。

- 文件整理与回收站
  - 预览删除、重复图片和小图片清理使用设置中的回收站文件夹；瀑布流翻页清理直接使用系统废纸篓。
  - 支持通过 `Cmd + Z` 撤销最近一次删除、重复清理或图片迁移操作；瀑布流移入系统废纸篓的图片需要在 Finder 中恢复。
  - 支持将当前文件夹的全部图片，或仅已打标签的图片，迁移到指定目录。
  - 目标目录存在同名文件时会自动追加编号，避免覆盖已有文件。
  - 可在设置中查看回收站占用空间，并手动永久清空回收站。

- 快速打开与最近记录
  - 可配置常用图片目录，在侧边栏下拉框中快速打开。
  - 记录最近打开的图片，最多保留 12 条。

- 服务端图片下载
  - 可从配置的 Leon 服务端随机获取 1～9999 张图片并下载到本地；每张图片下载成功后会立即通知服务端删除该图片记录。
  - 支持设置下载目录和 1～10 个并发下载线程。
  - 图片下载成功后，应用会请求服务端删除对应图片记录。

- 配置管理
  - 支持将标签、分类和竞赛评分导出为 JSON 文件。
  - 支持从 JSON 文件导入配置；导入会覆盖当前配置中对应的数据。

## 支持的图片格式

`.jpg`、`.jpeg`、`.png`、`.gif`、`.bmp`、`.webp`、`.tiff`、`.tif`、`.heic`、`.heif`

## 快速开始

### 环境要求

- macOS
- Node.js 和 npm

### 安装依赖

```bash
npm install
```

### 启动开发版本

```bash
npm start
```

### 构建 macOS 安装包

```bash
# 使用 electron-builder 构建 macOS 包
npm run build

# 明确构建 DMG 安装包
npm run build:dmg
```

构建产物输出到 `dist/`。当前打包配置的目标架构为 Apple Silicon（`arm64`）。

## 基本使用流程

1. 启动 MacImage，点击“打开文件夹”，选择包含图片的目录。
2. 首次使用建议先进入“设置 → 回收站”，选择一个用于存放待删除图片的目录。
3. 使用列表、网格或瀑布流视图浏览图片。
4. 在预览窗口或侧边栏中创建并添加标签，再通过标签筛选图片。
5. 需要筛选偏好时，使用“图片竞赛”累积 Elo 评分，或使用“大图瀑布流”将图片批量分流到目标目录和回收站。
6. 定期在“设置 → 数据管理”中导出配置进行备份。

## 快捷键

| 场景 | 快捷键 | 操作 |
| --- | --- | --- |
| 全局 | `Cmd + O` | 打开文件夹 |
| 图片预览 | `←` / `↑` | 上一张 |
| 图片预览 | `→` / `↓` | 下一张 |
| 图片预览 | `+` / `=` | 放大 |
| 图片预览 | `-` | 缩小 |
| 图片预览 | `0` | 重置缩放 |
| 图片预览 | `F` | 切换“红心”标签并进入下一张 |
| 图片预览 | `D` / `Delete` | 将图片移入回收站 |
| 全局 | `Cmd + Z` | 撤销最近一次文件操作 |
| 图片竞赛 | `1`～`8` | 选择对应编号的图片 |
| 大图瀑布流 | `↓` / `Space` | 下一页并整理 |
| 大图瀑布流 | `↑` | 返回上一轮，保留最近 5 轮 |
| 图片竞赛/预览 | `Esc` | 关闭当前窗口 |

为自定义标签设置单字母快捷键后，在图片预览中按对应字母即可切换该标签并自动进入下一张。`F` 和 `D` 已被系统功能占用，不能分配给标签。

## 重要说明

- 删除、重复清理和瀑布流整理都可能移动大量文件。执行前请确认回收站和目标文件夹设置正确。
- “清空回收站”会永久删除其中的图片，且不可撤销。
- 图片迁移使用移动操作，不是复制操作；源目录中的文件会被移走。
- 导入配置前请先备份当前配置，因为导入会覆盖标签、分类或竞赛评分中对应的数据。
- 服务端图片功能依赖 Leon 服务端可访问，并且下载成功后会删除服务端对应记录；建议确认服务端数据已有备份后再使用。
- 应用当前只扫描所选目录的直接子文件，不会自动扫描子目录。

## 数据与缓存位置

应用配置和缩略图缓存保存在 Electron 的 `userData` 目录中，主要包括：

- `macimage.db`：SQLite 数据库，保存标签、分类、评分、图片 hash、回收站和快捷目录等配置。图片路径 hash、图片标签和评分使用独立索引表，旧版聚合 JSON 数据会在首次启动时自动迁移。
- `config.json`：旧版本 JSON 配置。首次升级时会自动迁移到 `macimage.db`，并保留 `config.json.pre-sqlite.bak` 备份。
- `thumbnails/`：按图片指纹生成的小尺寸网格缩略图缓存。瀑布流和图片竞赛直接读取原图，不再持久化大图预览。
- `server-downloads/`：未指定下载目录时的服务端图片默认下载目录。

图片身份使用完整文件的 SHA-256。旧版前 64KB 指纹会在读取图片时自动升级，并保留已有标签和评分；首次升级需要重新读取文件生成指纹。旧版指纹曾经合并的数据无法反推出原始归属，因此会保留在对应图片上，升级后的标签和评分独立修改。旧版评分备份仍可导入。

瀑布流最近 5 轮保留在原位置，由主进程保存评分和布局；切换目录或重新加载后仍可返回。退出应用时会等待正在处理的轮次完成，再提交剩余整理。已经进入系统废纸篓的图片可在 Finder 中“放回原处”。

在 macOS 上，该目录通常位于：

```text
~/Library/Application Support/MacImage/
```

## 项目结构

| 文件 | 作用 |
| --- | --- |
| `main.js` | Electron 主进程、窗口、菜单和应用生命周期 |
| `preload.js` | 暴露给渲染进程的安全 IPC 接口 |
| `store.js` | 配置和图片元数据读写、迁移及事务 |
| `store-schema.js` | SQLite 表结构、索引及连接设置 |
| `main-ipc-handlers.js` | IPC 注册入口、文件夹和回收站操作 |
| `main-ipc-config.js` | 配置读写及 JSON 导入导出 |
| `main-ipc-file-operations.js` | 图片迁移、瀑布流整理等文件操作 |
| `main-ipc-server-images.js` | 服务端图片下载与服务端记录删除 |
| `image-collection.js` | 图片集合及按内容 hash 共享的元数据 |
| `image-query.js` | 标签筛选、字段排序和稳定随机顺序，不依赖 DOM |
| `image-preview-state.js` | 预览选择、路径同步、缩放和拖动状态，不依赖 DOM |
| `renderer-state.js` | 渲染进程共享状态和模型创建 |
| `renderer.js` | 主界面启动流程及按功能分组的事件注册 |
| `renderer-folders.js` | 目录加载、元数据更新和最近文件记录 |
| `renderer-gallery.js` | 列表、网格、缩略图和筛选控件 |
| `renderer-waterfall.js` | 大图瀑布流评分与整理 |
| `renderer-modal.js` | 图片预览、缩放、导航、标签及撤销操作 |
| `renderer-keyboard.js` | 预览、竞赛、设置和瀑布流的键盘分发与快捷键 |
| `renderer-settings.js` / `renderer-tag-settings.js` | 设置、分类和标签管理 |
| `renderer-duplicates.js` | 重复图片检测与清理 |
| `styles*.css` | 界面样式 |

图片查询每次读取集合中的最新元数据。排序返回新数组；筛选或刷新元数据时保留随机顺序，打开文件夹或重新选择随机排序时重置。`image-query.js` 需在 `renderer-state.js` 之前加载，顺序见 `index.html`。

`renderer-modal.js` 创建并持有预览状态，其他界面通过 `getCurrentModalImage()` 读取当前图片。删除和迁移只更新图片集合；`renderImages()` 通过 `syncModalWithImages()` 统一同步预览，同路径保留缩放，当前图片移除后选择相邻图片，筛选结果为空时关闭预览。`image-preview-state.js` 需先于 `renderer-modal.js` 加载。

运行 `npm test` 可验证模型、预览交互、回归用例和 HTML 脚本的实际初始化顺序，无需启动 Electron。初始化测试不验证浏览器布局。

数据库迁移和日常写入共用相同的 SQL 写入函数；事务由各操作统一管理，确保替换和迁移的相关变更一起提交。键盘事件依次检查预览、竞赛、设置、瀑布流，仅由匹配的界面处理。
